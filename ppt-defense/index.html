GROUNDING

每句话，都要对得上事实

引用不是脚注，是逐句核对后的结果。

01
句子切分

中文按 。！？；，英文按句号；每句独立核对。

02
数字对账

容差 max(0.02, |数值| × 0.002)；对不上就标记。

03
断言绑定

每句映射到 clause_id 或 prediction/shap 事实；无出处标"推断"。

04
无据丢弃

编造数字整句删除，verify 记录 dropped；答案里不再出现。

def ground(answer, facts, citations): for sent in split_sentences(answer): nums = extract_numbers(sent) bad = [n for n in nums if not in_fact_pool(n, facts)] if bad: drop(sent) # 整句丢弃 return { ok, coverage, claims, dropped }

覆盖率与丢弃数随答案返回；前端可展示"这句话没有依据"。

HYBRID RETRIEVAL

词法保准确，向量保召回

两路召回、一次融合、一次重排。

01
查询

原句 + 同义词；解读类用特征名，医学类保留原句。

02
词法 Top30

中文单字 + 二元词，TF-IDF；专有名词与编号更稳。

03
向量 Top30

bge-small-zh，512 维；换说法也能召回。

04
RRF 融合

score = Σ 1/(60+rank)；不依赖两路分数尺度。

05
LLM 重排

Top20 交给模型 listwise 排序；失败退回 RRF。

06
域过滤

医学/系统分流，分数 ≥8 才进引用，取 Top3。

lex = index.search(q, k=30, D) vec = embed.search(q, k=30) fused = rrf(lex, vec)[:20] ranked = llm_rerank(q, fused, top=3) return [c for c in ranked if c.score > 8]
FALLBACK

向量不可用 → 只走词法；重排超时 → 保留 RRF 顺序；都失败 → 旧单路检索。

TRADEOFFS

01 / GRAPH

自研 163 行

不引 LangGraph：依赖少、节点可单测、状态可回放；代价是生态与现成能力要自己补。

02 / RETRIEVAL

词法 + 向量

比纯词法多 90MB 模型和 9s 冷启动；换来的换说法召回，在医学术语上值得。

03 / STORAGE

SQLite

没有向量库、没有 Redis；1,035 条规模下内存余弦足够，部署只需一个文件。

04 / CONCURRENCY

单 worker

gunicorn 1 worker × 4 threads，避免多进程重复加载模型；代价是并发上限。

LIMITATIONS

四个局限，和对应的下一步

不把"能跑"说成"能临床用"。

01
词法仍有盲区

"靠不靠谱"搜不到"置信度"；同义词表只有 10 组，覆盖有限。

02
重排延迟 0.8–1.2s

LLM listwise 比向量检索慢；离线评测不包含这部分。

03
冷启动 9s

首次加载 ONNX 模型；之后热查询 0.9s。生产可用预热解决。

04
没有临床前瞻验证

只有 WDBC 回溯数据；不能声称临床有效性。
