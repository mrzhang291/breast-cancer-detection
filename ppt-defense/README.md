## 现场使用

```bash
# 直接双击打开即可，无需服务器
start index.html
```

- `←` `→` / 滚轮：翻页
- `P`：演讲者模式（含备注、计时、观众屏同步）
- `ESC`：宫格总览
- `B`：静态模式（关闭动画，低配投影仪更稳）
